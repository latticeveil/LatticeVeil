# V8.0.0 - Worldforge Convergence (Assets)

This asset release aligns with the Worldforge Convergence game release.

## Updated Content
- Synced from `LatticeVeilMonoGame/Defaults/Assets`.
- Includes current textures, model definitions, content data, and UI layout files used by official runtime builds.

## Runtime Behavior
- Launcher installs assets to `Documents/LatticeVeil/Assets`.
- Normal launch does not force replace existing assets unless files are missing.
- `Reset Assets` in launcher performs a full recovery reinstall.

## Compatibility Notice
- Older multiplayer world saves may not be compatible across major worldgen/sync updates.
